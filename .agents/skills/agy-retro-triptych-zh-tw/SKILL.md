# AGY 復古夜色三格漫畫風格

這個 skill 的工作不是單純「幫忙寫一段好看的 prompt」。

它的核心任務是：

1. 把使用者喜歡的畫面感拆成 **可重用的風格 DNA**
2. 把這套 DNA 轉成 **AGY 可直接使用的 prompt**
3. 之後同一套風格可以拿去畫別的角色、地點、情節

換句話說，這個 skill 比較像是在建立一套 **小型 style bible**，而不是只交出一次性的 prompt。

## 什麼時候用

在這些情境優先使用：

- 使用者想要「像某張圖那樣的氛圍」，但不打算把圖直接丟給 AGY
- 使用者想把一種畫風固定下來，之後反覆生成同一家族的圖片
- 使用者在意 **色調、構圖、分鏡節奏、鏡頭距離、情緒質地**
- 使用者說的是「這種感覺」「這種味道」「這種畫面語言」，而不是精確的美術術語
- 使用者想做 blind test，比較不同 prompt / 不同 skill 版本能不能穩定產出同類型畫面

如果使用者只是要一張一般性的插畫 prompt，沒有要抽出風格規則、沒有要維持跨場景一致性，就不一定需要這個 skill。

## 先抓對任務邊界

這個 skill 追的是 **相似的視覺語言**，不是逐項臨摹。

所以要刻意分開：

- **固定元素**：色調、鏡頭語法、分鏡節奏、情緒、材質感、描線與上色方法
- **可變元素**：角色、服裝、載具、城市、天氣、動作、道具

預設不要把參考畫面裡出現的單一物件當成風格本體。

例如：

- 飯店不是風格本體
- 敞篷車不是風格本體
- 可樂瓶不是風格本體
- UI 字樣、字幕、播放軸更不是風格本體

真正要保留的是：

- 低調復古的夜色氛圍
- 一主二副的三格分鏡結構
- 從中景到人物特寫再到細節特寫的鏡頭遞進
- 同一時空連續切鏡的敘事感

## 非風格元素：先排除

如果參考畫面是從影片、截圖、社群貼文來的，預設 **不要** 把這些東西寫進 prompt：

- 字幕
- 播放軸
- 音量圖示
- 時間碼
- 訂閱按鈕
- UI 浮層
- 水印
- 角落 logo
- 畫面上任何介面文字

只有使用者明確說「連這些都要保留成 faux screenshot / fake player UI」時，才把它們當成需求。

## 風格萃取流程

### 1. 先判斷使用者現在要什麼

優先分成三種輸出模式：

1. **直接出最終 prompt**
2. **先抽 style bible，再出 prompt**
3. **在既有 style bible 上做新場景變體**

如果使用者已經在講「我想固定一個風格，以後重用」，預設走第 2 或第 3 種。

### 2. 用可觀察語言描述風格

不要用空泛詞像是「有感覺」「很美」「動漫感」就結束。

至少拆成這幾層：

- **色彩**：低飽和、暖冷對比、亮部與暗部關係
- **光線**：夜景、室內暖光、城市反射、水面反光、車內微光
- **構圖**：幾格、格子比例、主副鏡頭分工
- **鏡頭距離**：中景、人物特寫、手部／物件細節特寫
- **敘事情緒**：安靜、享受、內斂、帶點懷舊
- **繪製媒介感**：乾淨描線、柔和賽璐珞上色、非寫實、非 3D

### 3. 先抓「固定語法」，再放場景內容

prompt 的前半段應優先固定：

- 作品媒介
- 畫風族譜
- 色調與光線
- 分鏡結構
- 鏡頭節奏
- 情緒基調

後半段再替換：

- 主角是誰
- 在哪裡
- 做什麼
- 有哪些當次場景才需要的道具

### 4. 避免過度複製原圖物件

如果使用者只說「同一個風格，換成別的情境」，就不要自動把舊場景裡的飯店、敞篷車、飲料瓶全部搬過去。

優先保留：

- 鏡頭編排
- 氣氛
- 配色關係
- 構圖節奏

而不是保留：

- 單一建築
- 單一品牌道具
- 單一角色髮型

## 這張參考圖的預設 style DNA

這個 skill 目前的第一版，是根據 `references/style-dna.md` 裡整理的視覺特徵來工作。

使用這份 style DNA 時，預設把它理解成：

- **低飽和復古夜景插畫**
- **帶漫畫分鏡的電影式靜態畫面**
- **一張圖裡同時包含建立場景、角色表情、手部／道具細節**

如果之後 blind test 發現某些描述不夠穩，優先改這份 DNA，而不是一直加更長更亂的 prompt。

## Prompt 建構原則

一段好的 AGY prompt，應該至少有這幾個區塊：

1. **畫風總句**
2. **分鏡結構**
3. **主場景描述**
4. **角色與動作**
5. **光線 / 色調**
6. **材質 / 上色 / 描線**
7. **避免事項**

### 建議的 prompt 內部順序

1. 先定義媒介與整體視覺語言
2. 再定義三格結構與各格鏡頭任務
3. 再描述當次場景與角色
4. 最後補上「不要出現什麼」

這樣比較不容易讓模型只抓到題材，卻忘了畫面語法。

## 預設輸出格式

如果使用者沒有指定格式，預設輸出：

### 1. 風格 DNA

- 3 到 6 點
- 用繁體中文
- 只講固定規則，不講當次偶然物件

### 2. AGY Prompt

- 給模型的最終 prompt
- 儘量寫成可以直接複製使用

### 3. 固定元素 / 可替換元素

- 固定元素：之後每次都要保留
- 可替換元素：角色、城市、時間、交通工具、情節

### 4. 避免事項

- 明列不要字幕、播放軸、介面文字、誤入 screenshot UI
- 避免高飽和 neon、過度 cyberpunk、3D 渲染感、照片寫實感

如果使用者明確只要 prompt，就縮成：

1. 最終 prompt
2. 3 到 5 個簡短補充注意事項

## 最少必要追問

如果資訊不夠，最多只問 3 題，而且要集中在最能改變畫面的變數：

1. 主角是誰／幾歲感／什麼氣質
2. 場景在哪裡／什麼時間／什麼天氣
3. 這次的核心動作是什麼

如果使用者已經給了足夠情境，就直接出稿，不要把對話拖成問卷。

## 風格守門規則

完成前檢查：

1. 這段 prompt 保留的是 **風格**，還是只是在複製物件？
2. 有沒有明確寫出三格分鏡，而不是只說 cinematic？
3. 有沒有把中景、人物特寫、細節特寫的鏡頭遞進寫清楚？
4. 色調是不是偏低飽和、復古、克制，而不是鮮豔炫目？
5. 有沒有避免字幕、播放 UI、社群截圖浮層？
6. 同一張圖裡的三格是否屬於 **同一段時空連續畫面**，不是三張無關拼貼？
7. 使用者如果下次換主角或換城市，這份 style DNA 還能不能用？

## Blind test 導向

做 blind test 時，優先比較這幾件事：

- 不看原圖時，是否仍能穩定生成同一家族的色調
- 三格分鏡是否有清楚的鏡頭階層
- 是否容易誤長出字幕 / UI / logo
- 是否太執著複製原圖道具，反而失去可重用性
- 換場景後，風格是否還在，而不是只剩題材在變
